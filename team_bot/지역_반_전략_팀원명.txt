배틀싸피 팀 대항전 전략 (제출 전 지역·반·명단을 실제 정보로 변경)

1) 명단
Player1: 지역반_이름1
Player2: 지역반_이름2
Player3: 지역반_이름3

2) 코드 순서
Player1_지역반_이름.py
Player2_지역반_이름.py
Player3_지역반_이름.py

3) 반별 전략
포탑 파괴 또는 두 번째 적 탱크 격파로 즉시 승리할 수 있으면 최우선 공격.
체력이 낮은 적 탱크에 집중하고, 메가탄 70 + 일반탄 30으로 두 번의 사격에 격파.
안전한 보급 시설에서는 메가탄 2발까지 우선 확보하며 무조건 10발을 모으지 않음.
아군 포탑 주변 3×3 이동 금지, 빈 사격·탄약 부족·보급 상한을 사전 검사.
현재 적 사선과 모래 누적 피해를 고려하여 생존 우선 경로를 매 턴 재계산.
막힌 사격과 아군 길막을 피하고, 비슷한 경로에서는 Player2·3이 다른 방향 선호.
탐색에 시간·상태 수 제한을 두어 런타임 지연 위험을 줄임.

4) 실행 전 확인
각 Python 파일 상단 NICKNAME을 본인의 지역반_이름으로 수정(12자 이내).
파일명을 실제 지역·반·이름으로 변경하고, Player 순서도 일치시키기.
사용 매뉴얼: v1.1.10(build 20250917), 제공된 팀전 규칙 이미지.
암호 키는 매뉴얼 예시의 시프트 17(해독 시 +9). 실제 경기 키가 다르면 변경.
기본 통신은 localhost:8747. 배포 기본 코드의 통신 규약이 다르면 통신부 연결 필요.
실제 공식 엔진 대전 검증은 미실시이며 승리를 보장하지 않습니다.
